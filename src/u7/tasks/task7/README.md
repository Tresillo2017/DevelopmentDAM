Crea una interfaz llamada Vehiculo que tenga los siguientes métodos:

void acelerar(int velocidad): Aumenta la velocidad del vehículo.

void frenar(): Reduce la velocidad del vehículo a 0.

void mostrarEstado(): Muestra la velocidad actual del vehículo.

Después, implementa esta interfaz en dos clases concretas:

Coche: Que tendrá un atributo marca y una velocidadActual.

Moto: Que tendrá un atributo modelo y una velocidadActual.

En el método main, instancia objetos de ambas clases y prueba sus métodos.
