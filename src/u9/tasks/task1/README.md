Utilizando la base de datos ebanca crea una aplicación con un menú que nos permita:

1) Mostrar todos los clientes
2) Eliminar clientes
3) Añadir clientes
4) Modificar el teléfono de un cliente
5) Buscar clientes por apellido (que muestre todos los clientes que tengan un apellido concreto que será solicitado por scanner)
6) Salir

IMPORTANTE: CONTROL DE ERRORES Y CREAR MÉTODOS QUE SE PUEDAN REUTILIZAR.
